# BUILD SPEC — T3.5 Footer Terminal ("serial console") + DevTools signature

**Verdict basis:** skeleton is `authentic-tty` (correct modality, correct no-JS/inert story, correct z-index, best a11y and focus discipline, instant output). Grafted from `discoverable-play`: trigger discoverability (dotted underline + hint, always-on for touch), Tab completion, Escape-vs-nav-menu isolation, focus-restore-only-if-inside, RM reboot note. Grafted from `engineer-showpiece`: shared `termPrompt` constant, truthful `uname` line, forced-colors input outline, resume PDF link in `cat`, tests in the existing `scripts/browser-smoke.mjs` harness, atomic commit plan. Everything else killed (see §12).

## 0. Locked design decisions

| Decision | Choice |
|---|---|
| Placement | Fixed bottom drawer: `position: fixed; inset-inline: 0; bottom: var(--kb, 0px)`, full-bleed background, content column capped at `--maxw-spine` (720px, matches the footer colophon column). DOM lives inside `Footer.astro`'s `.footer__inner` (fixed positioning → placement only affects tab order, which is correct there). Backtick works from anywhere with zero scroll jump and zero layout shift. |
| Size | `height: min(48vh, 24rem)` with a `min(48dvh, 24rem)` override line; `max-height: calc(100dvh - var(--kb, 0px))` guard for virtual-keyboard overlap (plain-`vh` fallback line first). |
| Modality | **Non-modal.** No dialog role, no focus trap, no scrim, page behind stays scrollable/interactive. Closed = `visibility: hidden` + `inert` attribute. Clicking outside does **not** close (a serial session stays attached until you detach). Escape / `exit` / `` ` `` / `[ exit ]` close it. |
| z-index | **150** — above `.nav` (100), **below** `.skip-link` (200) and `.boot` (300). The skip link is never buried. |
| Open/close motion | CSS class-toggle transition `transform: translateY(103%) ↔ none`, `var(--t) var(--ease-out)` (240ms), `visibility` flipped with matching transition-delay. Inherently interruptible; the existing global RM rule zeroes transition durations → instant snap for free. No `animation-timeline` anywhere in this feature, so the scroll-driven RM caveat does not apply. |
| Caret | **Native input caret**, `caret-color: var(--phosphor)`. No fake caret in the panel; the blinking `.caret` block stays only on the (closed) footer trigger line where it already lives. |
| Output pacing | **Everything prints instantly**, including `dmesg`. A ring-buffer read does not type itself out. No per-character or per-line animation of any kind. |
| Voice | Monochrome phosphor: output `--phosphor`, echoes/PS1/chrome `--phosphor-dim`, panel labels `--silkscreen`, solid `--bg-deep` panel. Exactly **one** link (resume PDF) rendered cyan `--accent-text` — the interactive voice. No scanlines, no CRT curvature, no glow on text. |
| Data | New `src/data/terminal.ts` derives every output line from `site.ts` (D-009/D-016). Only literals: shell furniture and public datasheet constants (AHT10 = 0x38, ADS1115 = 0x48 — the parts he actually interfaced per FIG. 02 / Radiogeet highlights; the output labels them as bench parts, not properties of this page). |
| Script delivery | Astro-processed `<script>` in `Terminal.astro` → bundled → CSP `'self'`. **No new inline scripts, no hash registration, `inline-scripts.ts` and `check-build.mjs` untouched.** All DOM via `createElement`/`textContent` — never `innerHTML` (D-008). |
| SR output | Scrollback is `role="log"` (implicit polite live region); each command's output appends as one block → one announcement. i2cdetect grid is `aria-hidden` with an sr-only one-sentence summary. |
| History / editing | ArrowUp/Down (in-memory, 32 max, consecutive dupes collapsed, draft preserved). Tab completes only on a **unique** prefix match, otherwise default Tab (focus moves — not a trap). Ctrl+L clears; Ctrl+C prints `^C` only when the selection is collapsed (copy is never hijacked). Scrollback capped at 60 blocks. |
| Touch | Footer trigger button (44px on coarse), hint always visible on coarse pointers, `[ exit ]` button 44px, input `font-size: max(16px, var(--fs-small))` on coarse (no iOS zoom), `enterkeyhint="send"`, `visualViewport` listener sets `--kb` while open. |
| Console signature | One `console.info` at module load, prompt colored from the live `--phosphor` token. No ASCII art. |
| Commands | Documented: `help` `whoami` `ls [projects]` `cat resume.txt` `dmesg` `uname -a` `i2cdetect` `open <section>` `clear` `reboot` `exit`. Unlisted flavor: `echo`, `sudo`. |

## 4. `src/components/Terminal.astro` (new, complete)

```astro
---
// T3.5 — footer serial console. Ships closed: server-rendered `inert` +
// visibility:hidden base state + an html:not(.js) display:none belt. Only
// the bundled script below can open it, so without JS it is invisible,
// unfocusable, and absent from the a11y tree (D-006). The script is
// Astro-processed → bundled → CSP 'self'; no inline-script hash work.
import { termPrompt } from "../data/site";
---
<section id="rr-term" class="term" aria-label="rr@embedded interactive terminal" inert>
  <div class="term__inner">
    <div class="term__head">
      <span aria-hidden="true">rr@embedded — serial console</span>
      <span class="term__baud" aria-hidden="true">115200 8N1</span>
      <button class="term__close" type="button">[ exit ]<span class="sr-only"> — close terminal</span></button>
    </div>
    <div class="term__scroll" role="log" aria-label="Terminal output" tabindex="0"></div>
    <form class="term__prompt">
      <span class="term__ps1" aria-hidden="true">{termPrompt}</span>
      <input
        class="term__input"
        type="text"
        autocomplete="off"
        autocapitalize="off"
        spellcheck="false"
        enterkeyhint="send"
        maxlength="120"
        aria-label="Terminal command input. Type help and press Enter."
      />
    </form>
  </div>
</section>

<script>
  import {
    PROMPT, sectionIds, COMMAND_NAMES, helpLines, whoamiLines, lsRootLines,
    lsProjectsLines, resumeLines, resumeLink, dmesgLines, unameLine,
    i2cLines, i2cNote, i2cSummary, motdLine, sudoLine, rmRebootNote,
  } from "../data/terminal";

  // ---- DevTools signature (once per load, one line, no ASCII art) ----
  const phosphor =
    getComputedStyle(document.documentElement).getPropertyValue("--phosphor").trim() || "#3AFB77";
  console.info(
    `%c${PROMPT}%c serial console attached — press \` or tap the footer prompt`,
    `color:${phosphor};font-family:monospace`,
    "font-family:monospace"
  );

  const term = document.getElementById("rr-term");
  const trigger = document.querySelector<HTMLButtonElement>(".footer__term-open");
  if (term && trigger) {
    const scrollEl = term.querySelector<HTMLElement>(".term__scroll")!;
    const input = term.querySelector<HTMLInputElement>(".term__input")!;
    const form = term.querySelector<HTMLFormElement>(".term__prompt")!;
    const closeBtn = term.querySelector<HTMLButtonElement>(".term__close")!;

    const MAX_BLOCKS = 60;
    const MAX_HISTORY = 32;
    let opener: HTMLElement | null = null;
    let motdShown = false;
    let rebooting = false;
    const history: string[] = [];
    let hIndex = -1;
    let draft = "";

    // ---- output ----
    // DOM APIs + textContent only — no innerHTML anywhere (D-008).
    const print = (lines: string[], opts: { echo?: boolean; grid?: boolean; sr?: string } = {}) => {
      const pre = document.createElement("pre");
      pre.className =
        "term__block" + (opts.echo ? " term__block--echo" : "") + (opts.grid ? " term__block--grid" : "");
      pre.textContent = lines.join("\n");
      if (opts.sr) {
        // Visual grid is aria-hidden; the log announces the sr summary instead.
        pre.setAttribute("aria-hidden", "true");
        const sr = document.createElement("p");
        sr.className = "sr-only";
        sr.textContent = opts.sr;
        scrollEl.append(pre, sr);
      } else {
        scrollEl.append(pre);
      }
      while (scrollEl.childElementCount > MAX_BLOCKS) scrollEl.firstElementChild!.remove();
      scrollEl.scrollTop = scrollEl.scrollHeight;
    };
    const echo = (cmd: string) => print([`${PROMPT} ${cmd}`], { echo: true });
    // The single link the terminal ever renders (resume PDF) — cyan voice.
    const printLink = (text: string, href: string) => {
      const p = document.createElement("p");
      p.className = "term__block";
      const a = document.createElement("a");
      a.href = href;
      a.textContent = text;
      a.setAttribute("download", "");
      p.append("→ ", a);
      scrollEl.append(p);
      scrollEl.scrollTop = scrollEl.scrollHeight;
    };

    // ---- virtual keyboard (touch): keep the prompt visible ----
    let vvHandler: (() => void) | null = null;
    const trackKeyboard = (on: boolean) => {
      const vv = window.visualViewport;
      if (!vv) return;
      if (on && !vvHandler) {
        vvHandler = () => {
          const kb = Math.max(0, window.innerHeight - vv.height - vv.offsetTop);
          term.style.setProperty("--kb", `${kb}px`);
        };
        vv.addEventListener("resize", vvHandler);
        vvHandler();
      } else if (!on && vvHandler) {
        vv.removeEventListener("resize", vvHandler);
        vvHandler = null;
        term.style.removeProperty("--kb");
      }
    };

    // ---- open / close (non-modal; interruptible CSS transition) ----
    const isOpen = () => term.hasAttribute("data-open");
    const open = () => {
      if (isOpen()) { input.focus({ preventScroll: true }); return; }
      opener = document.activeElement instanceof HTMLElement ? document.activeElement : null;
      term.removeAttribute("inert");
      term.setAttribute("data-open", "");
      trigger.setAttribute("aria-expanded", "true");
      if (!motdShown) {
        motdShown = true;
        print([motdLine]);
      }
      trackKeyboard(true);
      input.focus({ preventScroll: true });
    };
    const close = (refocus = true) => {
      if (!isOpen()) return;
      const hadFocus = term.contains(document.activeElement);
      term.removeAttribute("data-open");
      term.setAttribute("inert", "");
      trigger.setAttribute("aria-expanded", "false");
      trackKeyboard(false);
      // Restore focus only if it was ours to take, and never scroll the page.
      if (refocus && hadFocus) {
        const back = opener && opener.isConnected ? opener : trigger;
        back.focus({ preventScroll: true });
      }
      opener = null;
    };

    // ---- commands ----
    const run = (raw: string) => {
      const line = raw.trim().replace(/\s+/g, " ");
      echo(line); // empty Enter echoes a bare prompt line, like a real shell
      if (!line) return;
      if (history[history.length - 1] !== line) {
        history.push(line);
        if (history.length > MAX_HISTORY) history.shift();
      }
      hIndex = -1;
      draft = "";
      const [cmd0, ...args] = line.split(" ");
      const cmd = cmd0.toLowerCase();
      switch (cmd) {
        case "help":
          print(helpLines);
          break;
        case "whoami":
          print(whoamiLines);
          break;
        case "ls": {
          const target = (args[0] || "").replace(/\/$/, "");
          if (!target) print(lsRootLines);
          else if (target === "projects") print(lsProjectsLines);
          else print([`ls: cannot access '${args[0].slice(0, 32)}': no such file or directory`]);
          break;
        }
        case "cat": {
          const f = args.join(" ");
          if (f === "resume.txt") {
            print(resumeLines);
            printLink(resumeLink.text, resumeLink.href);
          } else if (!f) print(["cat: missing operand — try 'cat resume.txt'"]);
          else print([`cat: ${f.slice(0, 32)}: no such file`]);
          break;
        }
        case "dmesg":
          print(dmesgLines);
          break;
        case "uname":
          print([unameLine]);
          break;
        case "i2cdetect":
          print(i2cLines, { grid: true, sr: i2cSummary });
          print([i2cNote]);
          break;
        case "open": {
          const sec = (args[0] || "").toLowerCase();
          if (sectionIds.includes(sec)) {
            close(false); // native hash navigation owns focus/scroll next
            const el = document.getElementById(sec);
            if (window.location.hash === `#${sec}`) el?.scrollIntoView();
            else window.location.hash = `#${sec}`;
          } else {
            print([`open: unknown section — try: ${sectionIds.join(" · ")}`]);
          }
          break;
        }
        case "clear":
          scrollEl.replaceChildren();
          break;
        case "reboot":
          if (rebooting) break;
          rebooting = true;
          try { sessionStorage.removeItem("rr_boot"); } catch { /* intro just won't replay */ }
          print(["reboot: replaying boot sequence…"]);
          if (window.matchMedia("(prefers-reduced-motion: reduce)").matches) print([rmRebootNote]);
          window.setTimeout(() => window.location.reload(), 350);
          break;
        case "exit":
          close();
          break;
        case "echo":
          print([args.join(" ")]);
          break;
        case "sudo":
          print([sudoLine]);
          break;
        default:
          print([`sh: ${cmd.slice(0, 32)}: command not found — try 'help'`]);
      }
    };

    // ---- wiring ----
    trigger.addEventListener("click", () => (isOpen() ? close() : open()));
    closeBtn.addEventListener("click", () => close());
    form.addEventListener("submit", (e) => {
      e.preventDefault();
      const v = input.value;
      input.value = "";
      run(v);
    });
    term.addEventListener("keydown", (e) => {
      if (e.key === "Escape" && !e.isComposing) {
        e.preventDefault();
        // Layout's document-level Escape handler owns the mobile nav menu —
        // an Escape inside the terminal must close only the terminal.
        e.stopPropagation();
        close();
      }
    });
    input.addEventListener("keydown", (e) => {
      if (e.isComposing) return;
      if (e.key === "ArrowUp") {
        if (!history.length) return;
        e.preventDefault();
        if (hIndex === -1) { draft = input.value; hIndex = history.length; }
        if (hIndex > 0) hIndex--;
        input.value = history[hIndex];
        input.setSelectionRange(input.value.length, input.value.length);
      } else if (e.key === "ArrowDown") {
        if (hIndex === -1) return;
        e.preventDefault();
        hIndex++;
        if (hIndex >= history.length) { hIndex = -1; input.value = draft; }
        else input.value = history[hIndex];
        input.setSelectionRange(input.value.length, input.value.length);
      } else if (e.key === "Tab" && !e.shiftKey && !e.ctrlKey && !e.altKey) {
        // Complete only on a unique prefix match; otherwise Tab keeps its
        // default behavior (moves focus — reinforces "not a trap").
        const v = input.value.trimStart().toLowerCase();
        if (v && !v.includes(" ")) {
          const m = COMMAND_NAMES.filter((c) => c.startsWith(v));
          if (m.length === 1) { e.preventDefault(); input.value = m[0] + " "; }
        }
      } else if (e.ctrlKey && e.key === "l") {
        // Best effort: some browsers reserve Ctrl+L; `clear` always works.
        e.preventDefault();
        scrollEl.replaceChildren();
      } else if (e.ctrlKey && e.key === "c" && document.getSelection()?.isCollapsed) {
        // Only when nothing is selected — never hijack copy.
        e.preventDefault();
        echo(`${input.value}^C`);
        input.value = "";
        hIndex = -1;
      }
    });
    // Backtick toggle — never while typing in any field, never during boot.
    document.addEventListener("keydown", (e) => {
      if (e.key !== "`" || e.ctrlKey || e.metaKey || e.altKey || e.repeat || e.isComposing) return;
      const a = document.activeElement;
      if (
        a instanceof HTMLElement &&
        (a.tagName === "INPUT" || a.tagName === "TEXTAREA" || a.tagName === "SELECT" || a.isContentEditable)
      ) return;
      if (document.getElementById("boot-intro")) return;
      e.preventDefault();
      if (isOpen()) close();
      else open();
    });
    // Click anywhere non-interactive in the panel → focus the prompt,
    // unless the user is selecting output text.
    term.addEventListener("click", (e) => {
      if (!isOpen()) return;
      const t = e.target;
      if (t instanceof HTMLElement && t.closest("button, a, input")) return;
      if (!document.getSelection()?.isCollapsed) return;
      input.focus({ preventScroll: true });
    });
  }
</script>
```

## 7. A11y treatment

- **Trigger**: real `<button>`, `aria-controls="rr-term"`, `aria-expanded` kept in sync, name includes visible text, focus ring from the existing global `:focus-visible` rule (no override needed).
- **Panel**: `<section aria-label>` = named region landmark when open. Non-modal: no `role="dialog"`, no `aria-modal`, no trap, no scrim. Closed = `visibility: hidden` + `inert` — removed from AT tree, tab order, and hit-testing even mid-transition.
- **Output**: `role="log"` + `aria-label` → each appended block is one polite announcement (a whole `dmesg` dump = one utterance; `clear` announces nothing — removals are not announced, correct). i2cdetect grid `aria-hidden` + adjacent sr-only summary — a 128-cell hex grid is never read aloud.
- **Scrollback**: `tabindex="0"` (standard keyboard-scrollable-region pattern) with a quiet inset ring.
- **Focus**: open → input (`preventScroll`); close → restore only if focus was inside the terminal, to the element focused at open time (falls back to the trigger if disconnected), always `preventScroll: true`. `open <section>` skips restore and hands focus/scroll to native hash navigation. Escape inside the terminal `stopPropagation()`s so Layout's document-level handler never also closes the mobile nav.
- **Input**: `aria-label` carries the usage hint; PS1 span is `aria-hidden` decoration; native caret is the focus indicator plus PS1 brightening via `:focus-within`; explicit outline under forced colors.

## 8. No-JS story

`html:not(.js)` shows today's static colophon exactly; the button is `display: none` (B30 pattern); the panel is triple-belted (`inert` attribute + `visibility: hidden` base state + `html:not(.js) .term { display: none !important }`) and nothing can ever open it. Zero dead controls, zero content loss, zero navigation dependency.

## 9. Reduced-motion story

The only motion is the open/close transform/visibility transition — zeroed by the existing global RM rule (feedback stays: it still opens, instantly). No `animation-timeline` anywhere, so no explicit RM override is required. The trigger's `.caret` blink is already killed by the existing `.caret { animation: none }` RM rule; the native input caret is OS-governed. `reboot` under RM still reloads; the boot intro intentionally does not replay (existing `bootScript` behavior) and the terminal prints the explanatory `#` note so the outcome reads as designed, not broken. `open <section>` uses hash navigation → `scroll-behavior: auto` under RM via the existing rule at global.css line 10.

## 10. Edge cases

1. **Boot overlay active**: backtick ignored while `#boot-intro` exists (bootScript removes the node on dismiss/skip/RM/repeat visits); footer is inert during boot so the trigger is unreachable anyway.
2. **Backtick with focus in the terminal input**: editable-element guard → types a literal backtick (correct terminal behavior). Escape / `exit` close from the keyboard.
3. **Dead-key layouts** (many EU keyboards emit `"Dead"`, never `` ` ``): guard simply never matches; the footer button is the universal path.
4. **Modifier combos** (Ctrl+` VS Code muscle memory): ignored — only bare backtick toggles.
5. **Rapid toggle mid-transition**: class-toggle transitions reverse cleanly; `inert` always matches last intent; no `transitionend` dependence.
6. **Focus moved elsewhere before close**: `hadFocus` guard — closing never steals focus from the page.
7. **XSS via echoed input**: everything through `textContent`; unknown command/file names truncated to 32 chars; `maxlength=120` bounds input. Asserted in tests.
8. **sessionStorage blocked**: `reboot` try/catches and still reloads; double-`reboot` guarded by flag.
9. **Ctrl+C with a selection**: not intercepted — copy always works. Ctrl+L possibly browser-reserved — harmless, `clear` exists.
10. **Scrollback/history growth**: 60-block DOM cap, 32-entry history, consecutive dupes collapsed.
11. **i2c grid at 320px**: `--grid` block scrolls horizontally inside the log; page never scrolls sideways.
12. **iOS/Android keyboard**: `visualViewport` sets `--kb` (drawer lifts, max-height shrinks); listener attached only while open, removed and reset on close.
13. **`open` to the already-current hash**: falls back to `scrollIntoView()` (hash assignment would no-op).
14. **IME composition**: `isComposing` guards Escape, input keys, and the backtick toggle.
15. **Print while open**: `.term` hidden; static colophon forced back on.
16. **Bundle**: `terminal.ts` pulls `site.ts` into the client bundle — pure data, tree-shaken, low-single-digit KB gzip. Accepted; D-009 wins over duplication.

## 12. Rejected ideas (and why)

- **dmesg per-line stagger / entry fade-ins** (engineer-showpiece): the judge-killed typing pattern in disguise; a ring-buffer read prints instantly. Also would need extra RM overrides for nothing.
- **Backdrop-blur translucent drawer** (engineer-showpiece): glassmorphism, not instrument; solid `--bg-deep` is the serial-console read and costs nothing.
- **IO-driven "invite glow" + Layout reveal-selector edit** (discoverable-play): a decorative pulse bought with cross-file coupling; the blinking caret + dotted underline + hover/always-on hint already carry discoverability.
- **`uname` claiming eOS / Raspberry Pi / Yocto identity** (discoverable-play): conflates the webpage with the products it describes — D-016 adjacency. The site's uname describes the site.
- **z-index 250 above the skip link** (discoverable-play): the skip link (200) stays above everything but boot; terminal sits at 150.
- **Sticky-scroll window** (engineer-showpiece): output only ever appears on submit, when the user is at the prompt — always scroll to bottom, like a real shell.
- **Prompt inside the scrollback** (engineer-showpiece): authentic but complicates keyboard-lift and focus math; fixed prompt row is the serial-monitor layout.
- **Centered rounded "sheet"** (discoverable-play): full-bleed border-top drawer is the console metaphor; rounded sheet reads as a mobile modal.
- **Links throughout output** (whoami/ls externals): a terminal full of hyperlinks stops reading as a terminal; exactly one link (the resume PDF — the conversion moment) and `open projects` covers navigation.
- **`sudo` as "nothing here needs root"** (engineer-showpiece): the classic sudoers line is the recognized easter egg; keep the canon.
- **Focus trap / dialog semantics, ASCII-art signature, spring easings, per-character typing**: excluded by constraints and the judge's prior kills.
